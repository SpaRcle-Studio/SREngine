# Кодогенерация и рефлексия SREngine

## stdInclude модуля

- `<Module>/stdInclude.h` должен попадать в каждую единицу трансляции модуля по цепочке инклюдов (явно в каждый файл не нужно). Если хедер тянет только `Utils`, макросы `<Module>/macros.h` не определены и кодоген падает: `SR_CODEGEN_DLL_API_EXPORT_PHYSICS_MODULE` в `*.generated.hpp` → `error C2144: перед "void" требуется ";"`.
- Новый хедер модуля, не инклюдящий ни одного другого хедера этого модуля, первым инклюдит `<Module>/stdInclude.h`.

## Теги

Пишутся строго через `///` (не `//`). Строка `///` без тега перед `@property` может попасть в разбор — пояснение пиши тегом `@tooltip(...)` в той же строке: `/// @property @drag(0.01f) @tooltip(Полная высота капсулы без полусфер)`.

Значения `@range(...)` вставляются в C++ как выражения — для float с суффиксом `f`.

Члены класса:
- `@property` — свойство, доступное через рефлексию.
- `@virtualProperty` — свойство без своего поля, доступ через геттер/сеттер (напр. мировая `Position`).
- `@method` — метод, доступный через рефлексию.
- `@condition` — runtime-условие доступности свойства/метода (напр. зависит от enum другого свойства).
- `@dontSave` / `@dontLoad` — не сериализовать / не десериализовать.
- `@dontClone` — не клонировать при клонировании объекта.
- `@readOnly` — только чтение.
- `@debugOnly` — видно в редакторе только в режиме отладки.
- `@notNull` — запрет null; при создании инициализируется дефолтным значением, если оно есть.
- `@dontInitNull` — отключает авто-инициализацию для `@notNull`.
- `@hidden` — скрыть в редакторе.
- `@noHeader` — свойство (напр. класс) развёрнуто в редакторе без заголовка.
- `@evaluate` — метод не меняет состояние объекта (в основном для Flux).
- `@editorButton` — кнопка в редакторе, вызывающая метод.
- `@dontPack` — не упаковывать результат метода в `SR_UTILS_NS::Reflection::Value` (если он уже упакован).

Классы:
- `@abstract` — запрет создания.
- `@noCopyable` — запрет копирования.
- `@noMovable` — запрет перемещения.
